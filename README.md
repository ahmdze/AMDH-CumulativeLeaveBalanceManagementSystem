# نظام إدارة الإجازات التراكمية — الإصدار 3.0

نظام مكتبي عربي (RTL) لإدارة إجازات الموظفين وأرصدتها التراكمية، مكتوب بـ Python + PyQt6
مع قاعدة بيانات SQLite محلية، وتقارير Excel/PDF/HTML، ونسخ احتياطي تلقائي.

> **ضابط إداري معتمد:** الرصيد السالب **مسموح** ولا يُعد خطأً في هذا النظام، ويُعرض كمعلومة.
> أما قيم الإدخال غير الصالحة (عدد سالب في نوع إجازة عادي) فتُمنع، وتُستخدم للتسويات
> الإدارية نوع خاص اسمه **«تسوية رصيد»** يقبل القيم السالبة مع ذكر السبب.

---

## 1) التشغيل السريع

```powershell
# 1. تثبيت المتطلبات
python -m pip install -r requirements.txt

# 2. تشغيل البرنامج
python leave_system_deep.py

# أو تحديد مجلد بيانات مختلف
python leave_system_deep.py --data-dir "D:\AMDH-Data"
```

مجلد البيانات افتراضياً هو **مجلد البرنامج**، وإن لم يكن قابلاً للكتابة يُستخدم
`%APPDATA%\AMDH\LeaveSystem`. كل المسارات مطلقة، لذا يمكن تشغيل البرنامج من أي مكان.

## 3) الميزات

### إضافات الإصدار 3.1
- **5 ثيمات**: داكن (افتراضي)، فاتح، أزرق ليلي، زمردي، رملي دافئ — من الترويسة 🎨 أو الإعدادات.
- **تعدد اللغات**: العربية (المصدر) والكردية (سوراني) والإنجليزية، مع تغيير اتجاه الواجهة
  تلقائياً (RTL/LTR). الترجمة في ملفات `amdh_leave/locales/*.json` قابلة للتحرير.
- **إشعارات سطح المكتب (Tray)**: أيقونة في شريط النظام مع قائمة سريعة (النافذة، التنبيهات،
  لوحة المؤشرات، التقويم، تسجيل إجازة، نسخة احتياطية، الثيم، خروج)، فحص دوري للتنبيهات
  وإشعارات منبثقة، وخيار «الإخفاء إلى شريط النظام عند الإغلاق».
- **مشاركة التقارير**: إرسال Excel/PDF/HTML بالبريد الإلكتروني (SMTP) أو إلى تلغرام (Bot API)
  في خيط عمل غير حاجب، مع إعدادات محفوظة.
- **تشفير قاعدة البيانات (SQLCipher)**: تفعيل/إلغاء/تغيير كلمة المرور، ملف قفل
  `.amdh_lock.json` (ملح + بصمة تحقق بلا تخزين كلمة المرور)، وسكربت تثبيت
  `tools/install_sqlcipher.ps1`. يعمل البرنامج كاملاً بلا الحزمة مع تعطيل الميزة فقط.
- **شعارات وصور قابلة للاستبدال**: شعار البرنامج، شعار الدائرة، صورة المطوّر، وأيقونة التطبيق
  في `amdh_leave/assets/` — والملفات مسلَّمة **فارغة (شفافة)** مع بدائل مرسومة داخلياً حتى
  تضع صورك (راجع `amdh_leave/assets/README.md`). يمكن وضعها في مجلد البيانات `assets/`
  دون لمس البرنامج.
- **نافذة دخول جديدة**: شعاران (البرنامج + الدائرة)، اختيار اللغة، إظهار/إخفاء كلمة المرور،
  «تذكر اسم المستخدم»، وإيقاف المحاولات دقيقة بعد 5 محاولات فاشلة.
- **نافذة «حول» جديدة**: ثلاثة تبويبات (البرنامج/المطوّر/النظام) مع صورة المطوّر، معلومات
  الاتصال، إصدارات بايثون/Qt/SQLite، مسار البيانات، ونسخ معلومات النظام للحافظة.

### الأرصدة والحسابات
- معدل الاستحقاق: **يوم إجازة لكل 10 أيام دوام** (قابل للتعديل من الإعدادات).
- استبعاد أيام «خارج الرصيد» من أيام الخدمة (مثل إجازة 5 سنوات).
- **كشف حساب سنوي**: تفصيل كل سنة خدمة (خدمة/خارج الرصيد/صافي/مستحق/مأخوذ/مرحّل)،
  مع ترحيل وسقف ترحيل وصلاحية رصيد اختيارية.
- **تصفية نهاية الخدمة**: الرصيد المستحق مع إمكانية إدخال قيمة اليوم لحساب المبلغ.
- سقف المعدل السنوي (36 يوماً) **لا يُفرض افتراضياً** حفاظاً على الأرقام المعتمدة،
  ويمكن تفعيله من الإعدادات.
- دقة تقويمية كاملة: الشهر والسنة يُحسبان بالتقويم الفعلي (لا 30/365).

### ضوابط أنواع الإجازات (قابلة للتعديل من الواجهة)
لكل نوع: هل يُخصم من الرصيد؟ هل يُستبعد من أيام الخدمة؟ طريقة العد (تقويمية/أيام عمل)؟
سقف اختياري (سنوي/طوال الخدمة)؟ يتطلب رقم أمر؟ يخص جنساً معيناً؟ نوع تسوية؟
تُخزَّن الضوابط في قاعدة البيانات وتنتقل معها.

### السلامة والتدقيق
- **ترحيل آمن** لقاعدة الإصدار السابق مع **نسخة احتياطية تلقائية قبل الترحيل**.
- **حذف ناعم** لكل الموظفين والإجازات + سلة محذوفات للاستعادة.
- **سجل تدقيق**: من فعل ماذا ومتى (إضافة/تعديل/حذف/استعادة/تصدير/دخول).
- **معاملات ذرّية** لكل العمليات المركّبة (الاستيراد لا يترك قاعدة نصف محدَّثة).
- **نسخ احتياطي بدوران**: عند البدء/الإغلاق (إن تغيّرت البيانات)، قبل الاستيراد والترحيل،
  مع استعادة من الواجهة وفحص سلامة وضغط القاعدة.
- فهارس + وضع WAL + منع تشغيل نسختين على نفس القاعدة.
- سجلات دوّارة في `logs/app.log` وحوار خطأ ودّي بدل الإغلاق الصامت.

### الواجهة والتقارير
- لوحة مؤشرات (KPIs + رسوم بيانية بلا مكتبات خارجية).
- تقويم إجازات شهري (من في إجازة كل يوم) + تصدير.
- مركز إشعارات مع تصنيف الأهمية وتصدير Excel/HTML.
- Excel (RTL)، PDF بالعربية (تشكيل + اتجاه)، صفحات HTML جاهزة للطباعة.
- بحث فوري (مع تأخير 250ms)، فلترة بمكان العمل/المؤسسة، ترتيب رقمي صحيح،
  إخفاء/إظهار أعمدة مع حفظ الاختيار، تصدير «المعروض» أو «الكل»، اختصارات لوحة المفاتيح.
- مستخدمون وأدوار (مدير/مدخل بيانات/مطّلع) مع تقييد بالمؤسسة — **معطَّل افتراضياً**.
- مرفقات لكل إجازة (صورة/PDF للأمر).
- معالج استيراد Excel مع مطابقة أعمدة ومعاينة وتقرير تحقق.

## 8) الخصوصية

قاعدة البيانات والنسخ الاحتياطية والمرفقات والسجلات **مستثناة من Git** عبر `.gitignore`

```powershell

```
