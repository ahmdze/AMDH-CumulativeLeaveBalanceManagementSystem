# نظام إدارة الرصيد التراكمي للإجازات — الإصدار 1.0.0

نظام مكتبي عربي (RTL) لإدارة إجازات الموظفين وأرصدتها التراكمية، مكتوب بـ Python + PyQt6
مع قاعدة بيانات SQLite محلية، وتقارير Excel/PDF/HTML، ونسخ احتياطي تلقائي، وتشفير اختياري
عبر SQLCipher. يعمل **بلا إنترنت**، ويدعم طريقة العمل الموزّعة: مركز الدائرة + المؤسسات.

> **ضابط إداري معتمد:** الرصيد السالب **مسموح** ولا يُعد خطأً في هذا النظام، ويُعرض كمعلومة.
> ويُدعم **الرصيد الافتتاحي** للموظف: آخر رصيد متبقٍ حسب الحساب اليدوي، مع تاريخ الاحتساب
> ومن قام به وتفاصيله؛ ويُحسب من اليوم التالي لتاريخ الاحتساب، وتُمنع الإجازات التي تخصم
> من الرصيد قبل/عند ذلك التاريخ.

## 1) التشغيل السريع

```powershell
py -m pip install -r requirements.txt   # أو python -m pip ...
py leave_system_deep.py                 # أو python leave_system_deep.py
```

أو بعد البناء:

```
dist\AMDH-Leave\AMDH-Leave.exe
```

- البيانات افتراضياً في مجلد **`data` بجانب الـ EXE** في النسخة المغلّفة، وفي جذر المشروع
  عند التشغيل من المصدر. يمكن تحديد مجلد آخر:
  ```
  AMDH-Leave.exe --data-dir "D:\AMDH-Data"
  ```
- إذا لم يكن `data` قابلاً للكتابة يُستخدم `%PROGRAMDATA%\AMDH\LeaveSystem` ثم
  `%APPDATA%\AMDH\LeaveSystem`.
- **لا تضع البرنامج في `Program Files`** إن أردت بيانات محمولة بجانبه؛ استخدم مجلداً
  قابلاً للكتابة مثل `C:\AMDH`.
- عند تحديث البرنامج: استبدل `AMDH-Leave.exe` و`_internal` فقط، وأبقِ `data` كما هي.

## 3) طريقة العمل الموزّعة

### أ) في مركز الدائرة
1. شغّل البرنامج، وغيّر كلمة مرور `admin` الافتراضية فوراً.
2. افتح **🏥 المؤسسات** وأضف المؤسسات (أو استوردها من Excel).
   لكل مؤسسة يُنشأ مستخدم مرتبط تلقائياً بكلمة مرور تُعرض مرة واحدة.
3. اختر المؤسسة ← **📦 تجهيز نسخة المؤسسة**:
   - يُطلب إدخال **كلمة مرور admin للصيانة** (تُحفظ بصمة فقط، ولا تُكتب في الحزمة).
   - يُنشأ مجلد/ZIP جاهز يحوي نسخة البرنامج + `data` + قاعدة مؤسستها + مفتاح فتح تلقائي
     + `بيانات_الدخول.txt` + `تعليمات_التشغيل.txt`.
   - يُسجَّل مفتاح النسخة وكلمة مرور الصيانة في **خزنة كلمات المرور**.
4. في نهاية كل شهر: **📥 استيراد من مؤسسة** ← اختر ملف `.amdhz` ← راجع المعاينة
   والتقرير ← نفّذ. تُؤخذ نسخة احتياطية تلقائياً، ويمكن التراجع بضغطة.
5. تابع **⚠ المؤسسات التي لم تُرسل** لمعرفة المتأخرين.

### ب) في المؤسسة
1. انسخ الحزمة إلى قرص محلي (مثل `C:\AMDH\H1`) وشغّل `AMDH-Leave.exe` أو `تشغيل.bat`.
2. سجّل الدخول بحساب «مدخل بيانات» من `بيانات_الدخول.txt` (يرى موظفي مؤسسته فقط).
3. أدخل الموظفين والإجازات والمرفقات.
4. في نهاية الشهر: **📤 تصدير للمركز** ← اختر «الشهر الحالي» أو فترة من/إلى ←
   احفظ `.amdhz` ← سلّمه للمركز.
5. حساب `admin` في النسخة للصيانة فقط، وكلمة مروره لدى المركز.

> ملف النقل `.amdhz` **منقّى** (بلا مستخدمين ولا سجل تدقيق) لكنه **غير مشفّر**؛
> انقله عبر وسيط آمن. النسخ الاحتياطية المحلية مشفّرة عند تفعيل التشفير.

## 4) الميزات

### الأرصدة والحسابات
- معدل الاستحقاق: **يوم إجازة لكل 10 أيام دوام** (قابل للتعديل).
- استبعاد أيام «خارج الرصيد» من أيام الخدمة (مثل إجازة 5 سنوات).
- **كشف حساب سنوي** بتفصيل كل سنة خدمة، مع ترحيل وسقف وصلاحية اختيارية.
- **تصفية نهاية الخدمة** مع إمكانية إدخال قيمة اليوم.
- دقة تقويمية كاملة (لا 30/365).

### الرصيد الافتتاحي (قبل تشغيل النظام)
- لكل موظف: **آخر رصيد متبقٍ** حسب الحساب اليدوي، وتاريخ الاحتساب، ومن قام بالحساب،
  وتفاصيل/مرجع الحساب.
- الحساب: `الرصيد الافتتاحي + المستحق بعد التاريخ − إجازات بعد التاريخ`.
- يُحسب من **اليوم التالي** لتاريخ الاحتساب؛ وإجازات ما قبل/عند التاريخ (التي تخصم من
  الرصيد) **ممنوعة**، أما الإجازات المستبعدة من الخدمة (مثل الأمومة) فيُحتسب الجزء
  الواقع بعد التاريخ فقط.
- تعديل الرصيد لاحقاً مسموح مع **تدقيق** وتنبيه أنه يعيد ضبط الأساس.
- الموظفون بلا رصيد افتتاحي: أرقامهم لا تتغير إطلاقاً.

### تصدير واستيراد الموظفين (Excel)
- **تصدير كل الحقول** القابلة للإدخال: البيانات الأساسية + الحالة + الرصيد الافتتاحي.
- **قالب استيراد** جاهز مع ورقة تعليمات، ومعالج معاينة وتحقق ووضعي تحديث/إضافة.
- التحقق: تاريخ المباشرة إلزامي، وتفاصيل الرصيد الافتتاحي إلزامية عند تفعيله، ومنع
  تعارضه مع إجازات موجودة.

### ضوابط أنواع الإجازات
لكل نوع: يخصم من الرصيد؟ يُستبعد من الخدمة؟ طريقة العد؟ سقف؟ يتطلب أمراً؟ جنس؟
تُخزَّن في قاعدة البيانات وتنتقل معها.

### المؤسسات والدمج
- نافذة كاملة: إضافة/تعديل/حذف، استيراد وتصدير Excel، قالب جاهز.
- مستخدم مرتبط تلقائياً، مقيَّد بمؤسسته، ويستطيع تصدير بياناتها فقط.
- **بطاقة بيانات الدخول**: بعد إنشاء المؤسسة/تصفير المستخدم تظهر نافذة باسم المستخدم
  وكلمة المرور، مع **معاينة وطباعة** صفحة A4 وسلّمها ورقياً لموظف المؤسسة، أو حفظها PDF.
- **الرقم الوظيفي هو الهوية**: الموظف واحد مهما تنقّل، والانتقال يُسجَّل في `employee_moves`.
- **لا حذف إطلاقاً** عند الدمج: إضافي/تحديثي فقط، والحذف الناعم ينتقل.
- **معاينة كاملة** قبل الكتابة، ثم معاملة واحدة + نسخة احتياطية + تقرير + تراجع.
- **متابعة شهرية**: آخر استيراد لكل مؤسسة + «من لم يُرسل هذا الشهر».

### الصلاحيات والواجهة النظيفة
- الواجهة **تُخفي** كل صفحة/زر لا يملك المستخدم صلاحيته، بدل تعطيله.
- **مدخل بيانات المؤسسة يدير كل ما يخص مؤسسته**: إضافة/تعديل/حذف الموظفين،
  الإجازات والمرفقات، العطل الرسمية، التشفير والخزنة، عمليات قاعدة البيانات،
  سلة المحذوفات، والنسخ الاحتياطي، وكل تبويبات الإعدادات.
- لا يظهر له: المستخدمون، المؤسسات، ضوابط أنواع الإجازات، سجل التدقيق،
  واستيراد ملف مؤسسة.
- **العطل الرسمية**: يديرها مدير النظام ومدخل البيانات (إضافة/حذف)، وتظهر للجميع.
- **الأمومة**: لا تُخصم من الرصيد، وتُستبعد أيامها من أيام الخدمة المستحقة.
- سجل الإجازات والمرفقات: أزرار الإضافة/التعديل/الحذف تظهر حسب الصلاحية.

### السلامة والتدقيق
- ترحيل آمن مع نسخة قبل الترحيل، وحذف ناعم وسلة محذوفات، وسجل تدقيق.
- نسخ احتياطي بدوران عند البدء/الإغلاق/قبل الاستيراد، مع استعادة وفحص سلامة.
- فهارس + WAL + منع تشغيل نسختين على نفس البيانات، وسجلات دوّارة.

### التشفير وخزنة كلمات المرور
- **SQLCipher** (حزمة `sqlcipher3`): تفعيل/إلغاء/تغيير كلمة المرور من الإعدادات.
- نسخ المركز الاحتياطية مشفّرة بكلمة المرور الرئيسية نفسها.
- **نسخ المؤسسات** تُفتح تلقائياً بمفتاح `data/.amdh_dbkey` (بلا سؤال كلمة مرور)،
  مع بقاء تسجيل الدخول إلزامياً.
- **خزنة كلمات المرور** في حساب `admin`: كلمة مرور القاعدة، مفاتيح نسخ المؤسسات،
  كلمات مرور الصيانة، مع **بطاقة استرداد** خارجية للطباعة.
- **تنبيه**: فقدان كلمة مرور القاعدة أو ملف المفتاح = فقدان الوصول إلى البيانات المشفّرة.

### الواجهة والتقارير المتقدمة
- **بحث متقدم**: فلترة متعددة المعايير (اسم، نوع، حالة، مؤسسة، تاريخ) مع تصدير Excel.
- **بطاقات الموظفين**: بطاقة A6 شاملة (الاسم، الرقم الوظيفي، المؤسسة، الرصيد) مع معاينة وطباعة PDF.
- **تقارير مخصصة**: بناء حر باختيار الحقول والتجميع والفلترة، مع حفظ القوالب وإعادة استخدامها.
- **لوحة مؤشرات متقدمة**: رسوم بيانية شاملة (أعمدة، دائري، خطي) + إحصائيات متقدمة (متوسط الإجازات، أكثر الأنواع استخداماً، نسبة الاستهلاك).
- **العطل الرسمية القابلة للتكرار**: إضافة عطلة مع خيار "تكرر سنوياً" — تُضاف تلقائياً لكل سنة جديدة.
- **تأخير تصاعدي** على تسجيل الدخول: 1ث، 3ث، 10ث، 30ث قبل القفل بعد 5 محاولات.

- endpoints شاملة: الموظفين، الإجازات، الأرصدة، التقارير، لوحة المؤشرات، العطل، المؤسسات، والتصدير.
