# نظام إدارة الرصيد التراكمي للإجازات

نظام مكتبي عربي لإدارة إجازات الموظفين وأرصدتها التراكمية، مكتوب بـ Python + PyQt6 مع SQLite.

## الميزات الرئيسية

- حساب رصيد الإجازات التراكمية بدقة تقويمية كاملة
- دعم طريقتي الاحتساب: مستمر وسنوي
- تشفير قاعدة البيانات بـ SQLCipher
- نظام مؤسسات موزع مع ملفات نقل
- تقارير PDF وExcel بالعربية
- نسخ احتياطية تلقائية
- لوحة مؤشرات ورسوم بيانية

## التشغيل

```bash
pip install -r requirements.txt
python leave_system_deep.py
```

## الاختبارات

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -v
```
