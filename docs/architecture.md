# البنية المعمارية

## طبقات النظام

1. **طبقة البيانات** (`db/`): إدارة قاعدة البيانات SQLite مع التشفير والترحيلات.
2. **طبقة النماذج** (`models.py`): تعريفات البيانات (Employee, Leave, Institution...).
3. **طبقة الخدمات** (`services/`): منطق العمل (حساب الرصيد، الدمج، التقارير...).
4. **طبقة التصدير** (`exporters/`): تصدير Excel وPDF وHTML.
5. **طبقة الواجهة** (`ui/`): النافذة الرئيسية والحوارات ولوحة المؤشرات.

## قاعدة البيانات

تتكون من 12 جدولاً:
- `employees`: بيانات الموظفين
- `leaves`: الإجازات المسجلة
- `leave_rules`: قواعد أنواع الإجازات
- `holidays`: العطل الرسمية
- `app_users`: مستخدمو النظام
- `audit_log`: سجل التدقيق
- `attachments`: المرفقات
- `app_meta`: الإعدادات
- `institutions`: المؤسسات
- `imports`: سجل الاستيراد
- `employee_moves`: انتقال الموظفين
- `transfer_manifest`: متابعة النقل

## التشفير

يستخدم SQLCipher مع PBKDF2-HMAC-SHA256 و200,000 تكرار.
