# التصميم التقني

### التقسيم المقترح لـ db.py

**المشكلة**: ملف `db.py` يحتوي 1400 سطر يجمع المخطط، الترحيلات، الاستعلامات، والتدقيق.

**الحل**: تقسيم إلى 4 ملفات:

```
amdh_leave/db/
  __init__.py      # فئة Database الموحّدة (تستورد من الوحدات)
  schema.py        # CREATE TABLE، أعمدة إضافية، فهارس، بيانات افتراضية
  migrations.py    # _migrate، _backfill، نسخ احتياطي قبل الترحيل
  queries.py       # list_employees، list_leaves، add_leave، إلخ
```

**مبدأ هام**: الاستيرادات الحالية من `amdh_leave.db` تبقى تعمل لأن `__init__.py` يعيد تصدير كل شيء.

### تأخير تصاعدي على تسجيل الدخول

في `dialogs_login.py`:
- المحاولة 1 الفاشلة: تأخير 1 ثانية
- المحاولة 2: تأخير 3 ثوانٍ
- المحاولة 3: تأخير 10 ثوانٍ
- بعد 5 محاولات: قفل 60 ثانية (موجود حالياً)

### لوحة تحكم إدارية متقدمة

تعزيز `dashboard.py`:
- إضافة `PieChart` للإجازات حسب النوع
- إضافة `LineChart` للإجازات حسب الشهر
- KPIs جديدة: متوسط الرصيد، أكثر أنواع الإجازات
- فلترة حسب المؤسسة

### API REST شامل

```
amdh_leave/api/
  __init__.py
  main.py          # تطبيق FastAPI
  auth.py          # مصادقة Bearer Token
  employees.py     # CRUD للموظفين
  leaves.py        # CRUD للإجازات
  balance.py       # حساب الرصيد
  reports.py       # تقارير
  dashboard.py     # بيانات لوحة المؤشرات
  holidays.py      # عطل رسمية
  institutions.py  # مؤسسات
  export.py        # تصدير Excel/PDF
```

### عطل رسمية قابلة للتكرار

إضافة عمود `recurring INTEGER DEFAULT 0` في جدول `holidays` مع ترحيل جديد.

### تقارير مخصصة

- اختيار الحقول من قائمة
- اختيار التجميع والفلترة

  - توزيع حسب المؤسسة
